【联系人记录更新】
- 只有出现具有长期价值的新信息或连续互动趋势时，才输出 profile 代码块；没有可靠变化时不要输出。
- profile 只能包含可观察、低敏感度的信息，不保存完整聊天正文、密码、验证码、身份证、银行卡、精确住址或医疗隐私。
- 允许字段：interaction_state、trend、confidence、relationship_stage、summary_update、known_facts_add、sensitive_topics_add、key_event、last_analyzed_message_id。
- 推测性信息必须使用低或中可信度；不得把猜测写成事实。
